COMMIT

Adds ₹1,000 to the account and permanently saves the transaction to the database.

ROLLBACK

Temporarily adds ₹2,000 to the account, then immediately rolls back, undoing the change.

SAVEPOINT

Adds ₹1,000, creates a savepoint, adds another ₹2,000, then rolls back to the savepoint (only keeps first ₹1,000).

DATABASE CONCEPTS

ACID Properties

A
Atomicity

All operations within a work unit are completed successfully; otherwise, the transaction is aborted and previous operations are rolled back.

C
Consistency

Ensures that the database properly changes states upon a successfully committed transaction, maintaining all defined rules.

I
Isolation

Enables transactions to operate independently. Concurrent execution results in the same state as serial execution.

D
Durability

Ensures that the result of a committed transaction persists in case of a system failure.
